1. CameraKit is a library built in .NET Framework 4.6.1 using C# for Visual Studio Community 2019.

Using the Code
1. Add reference items into your project:
	CameraKit.dll
2. Go to .\AssetsLibrary and copy the following items to your executable path
3. using library in your code
	using com.ipevo.windows.CameraKit;
	using com.ipevo.windows.ToolKit;
